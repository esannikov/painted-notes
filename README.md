# Ноти на картинах

Робочий звіт (жовтень 2026): як машина читає намальовані ноти на старих картинах і знаходить твір у великих нотних базах.

Сторінка: https://esannikov.github.io/painted-notes/

Зображення: Метрополітен-музей (CC0), Рейксмузей, Вікісховище, SMK (суспільне надбання), Королівська бібліотека Бельгії (CC0), Клівлендський музей мистецтва (CC0). Вирізки, розмітка і текст: Євген Санніков, Claude (Anthropic).
